# WEBATHON
Student marketplace website

This is our 5-hour Webathon Project and we have built it using HTML, CSS, and JavaSript eaturing a bold neo-brutalist cartoon aesthetic. The project features interactive resource cataloging, dynamic modal overlays, smooth hidden-scrollbar UI containers, and a custom CSS design system. 

Campus Circular is a resource-sharing digital platform for a college community that enables students to discover, share, lend, borrow, donate, and request resources. Our project consist of -

Neo-Brutalist UI: Retro cartoon aesthetic with bold outlines, vibrant colors, and hidden-scrollbar containers.
Resource Exchange Catalog: Filterable grid supporting item renting, bartering, and donating.
Smart AI Search: Instant query bar for discovering academic and personal resources quickly.
Item Lifecycle Tracker: Interactive stepper showing real-time progress from listing to final exchange.
Sustainability Dashboard: Community metrics panel showcasing total items shared and environmental impact.
Dynamic Modals & Auth: Seamless pop-up overlays for account authentication and detailed item views.

Campus Circular demonstrates the integration of a modern component-driven front-end, custom CSS design systems, and responsive user experience patterns into an engaging, community-focused web platform.
